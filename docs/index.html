为读英文网页而做

划词、整页对照、自己的模型，三件事就够用。不捆绑任何翻译服务商。

划词自动翻译

选中单词或句子，松手即译。译文显示在选区旁的浮层里，不必再点一次按钮。

全文中英对照

在原英文段落下方插入中文，阅读节奏不被打断。随时可以取消对照。

自配大模型 API

兼容 OpenAI、DeepSeek、通义兼容端或自建接口。Key 只存在本地，请求由后台脚本发出。

右键一键翻译

菜单里可翻译选中文本、翻译整个页面，或清掉当前页的对照译文。

三步开始用

  1. 构建并加载

    克隆仓库后执行 npm install && npm run build，在 Chrome 扩展页加载 dist 目录。

  2. 接入你的模型

    打开设置，填写 Base URL、API Key 和模型名，点「测试连接」。

  3. 在网页里划词

    选中英文即出译文；需要整页对照时，用 Popup 或右键菜单一键翻译。
